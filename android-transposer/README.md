# 安卓 MIDI 移调器

这是一个第一版安卓测试项目，使用手机的 USB MIDI 接口向电子琴发送移调 SysEx。

## 操作逻辑

- 12 个调键设置基础调：C、C#、D、Eb、E、F、F#、G、Ab、A、Bb、B。
- `+` 把步长加 1，`-` 把步长减 1，步长范围为 1～12。
- `♯` 让当前总移调量增加一个步长；`♭` 让当前总移调量减少一个步长。
- 顶部显示当前调名、当前总移调半音数和步长数字。
- 顶部 MIDI 状态区会显示是否检测到并打开了 MIDI 设备。

例如：步长为 1 时按一次 `♯` 是升 1 个半音；步长改为 2 后再按一次 `♯` 是再升 2 个半音。

## 连接

安卓手机需要 USB OTG 转接头。直连琴的 USB MIDI 口，或连接带 MIDI OUT 的 USB-MIDI 接口。

## 编译

用 Android Studio 打开 `android-transposer` 目录，等待 Gradle 同步后运行 `app`。也可以把整个目录提交到 Git 服务后使用 Android 构建环境生成 Debug APK。
